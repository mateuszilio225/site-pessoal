Site pessoal de mateuszilio225.

## Estrutura

- `assets/` — estilos, imagens e scripts

## Desenvolvimento local

Abra `index.html` no navegador ou rode um servidor estático:

```powershell
python -m http.server 8000
```

Depois acesse http://localhost:8000
